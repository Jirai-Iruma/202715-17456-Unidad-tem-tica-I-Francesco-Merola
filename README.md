# Calculadora Financiera de Préstamos - Ingeniería Económica

## Descripción del Proyecto
Aplicación web interactiva para el cálculo de préstamos, cuadros de amortización y visualización de diagramas financieros (Flujo de efectivo y Saldo de efectivo), desarrollada para la asignatura de Ingeniería Económica en la UCAB.

---

## Instrucciones de Uso
1. Abrir el archivo index.html en cualquier navegador web.
2. Ingresar los parámetros del préstamo:
   - Cantidad solicitada
   - Tasa de interés anual (%)
   - Plazo en meses
3. Seleccionar la divisa deseada (€, $, £, Bs.).
4. Presionar el botón "Calcular" para obtener la cuota mensual, las gráficas interactivas y la tabla de amortización.
5. Utilizar el botón correspondiente para exportar el reporte generado a formato PDF.

## Desglose de Prompts y Roles de Desarrollo

### Actividad 1: Fundamentos y Análisis en Hoja de Cálculo
- Integrante 1 (Coordinador): Consolidación, formato de entrega y redacción del análisis crítico del modelo de negocio.
- Integrante 2 (Teoría): Sistematización de conceptos del Apéndice A (Blank, 2012) para el mapa conceptual.
- Integrante 3 (Analista 1): Resolución de ejercicios de Valor Presente y Valor Futuro, junto con tablas para Cash Flow y Cash Balance.
- Integrante 4 (Analista 2): Resolución de anualidades, series aritméticas y aplicación de la herramienta Buscar Objetivo (Goal Seek).

### Actividad 2: Desarrollo de la Aplicación Web
- Integrante 5 (Front-End Base): Estructura HTML5, CSS3 y JavaScript base para la calculadora responsive.
- Integrante 6 (Datos y Tablas): Integración de Chart.js para gráfico de Capital vs. Intereses y generación de la tabla de amortización.
- Integrante 7 (Financiero y Exportación): Lógica de gráficos de Cash Flow Diagram, Cash Balance Chart y generación de PDF mediante jsPDF.
- Integrante 8 (UX/UI y Calidad): Redacción de instrucciones, formateo de citas bajo Normas APA 7ma Edición y sección de créditos.
